# ChatGPT Projects Compatibility

Treat `AGENTS.md` as the canonical policy entry point and include the repository in the Project context when available. Because different ChatGPT coding surfaces can expose different tools and file-loading behavior, do not assume automatic discovery semantics identical to Codex, Claude Code, or Copilot.

For prompt-only workflows, use `MASTER-PROMPT.md` and provide project-specific context separately.

The repository files remain the source of truth; the chat prompt should not invent a second conflicting policy.
