# Architecture Checklist

Before changing architecture, inspect:

- repository boundaries;
- entry points;
- module ownership;
- data flow;
- external interfaces;
- persistence;
- authentication and authorization;
- background jobs;
- configuration;
- observability;
- deployment topology;
- test seams;
- generated code;
- compatibility requirements;
- migration strategy.

Search for an existing implementation of the requested pattern. Record constraints that make one alternative safer than another.
