Produce 3 materially different visual directions for the requested surface.

For each direction identify the visual thesis, layout philosophy, typography, color roles, content/data treatment, interaction language, distinctive element and risks.

Reject the first obvious solution when it is generic. Prefer structural differentiation over decoration.

Do not write implementation code. Return concise evidence suitable for synthesis into .ai/templates/design-brief.md.
