# Commit Message

## Subject

<type>(<scope>): <imperative summary>

## Body

<Why this change exists and any important context.>

## Footer

<Optional issue or breaking-change references.>

## Examples

```text
feat(api): add health endpoint
fix(auth): reject expired sessions
docs: explain local setup
```

## Commit gate

A commit is a repository mutation. Create one only when the user or repository workflow explicitly authorizes it.

## Verification note

Do not claim tests passed unless they actually passed before the commit was created.
