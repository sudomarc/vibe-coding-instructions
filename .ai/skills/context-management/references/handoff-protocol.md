# Handoff Protocol

A handoff is a state snapshot, not a conversation summary.

Required fields:

- objective;
- repository status;
- applicable instructions;
- completed batches;
- changed files;
- verification evidence;
- current failure or blocker;
- decisions already made;
- open questions;
- risks;
- exact next action;
- completion criteria.

Do not claim completion in a handoff. Preserve the state needed for the next session to verify it.
