Inspect repository instructions, UI conventions, nearest existing components, responsive behavior and state requirements before editing.

Implement the smallest coherent change. Prefer composition over duplication and existing primitives over new libraries. Keep browser-only code and client state at the established boundaries.

Run focused tests and type or lint checks where applicable. Use browser verification for user-visible changes when available. Inspect the final diff before completion.
