# Next.js Skill

Inspect the installed Next.js version and project-generated instructions first. Use version-matched documentation and existing repository patterns.

Check Server and Client Component boundaries, server data access, browser state, route handlers, static or dynamic behavior, caching and revalidation, loading and error boundaries, metadata, images and client bundle impact.

Do not assume a feature needs a client component. Verify framework behavior in the actual repository.
