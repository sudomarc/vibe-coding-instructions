# Git Skill

Inspect status and diff before mutation. Preserve unrelated work. Prefer small meaningful commits when the user requests commits. Follow existing message conventions. Never rewrite shared history or discard changes without authorization.

References: `references/git-safety.md`, `references/commit-conventions.md`, `examples/commit-example.md`.
