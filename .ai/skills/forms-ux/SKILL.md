# Forms UX Skill

Treat a form as a lifecycle: idle, editing, validating, submitting, success or recoverable error.

Check labels, input types, defaults, validation timing, accessible errors, pending state, duplicate submission, retry, preserved input, server validation and success confirmation.

Error messages should explain the problem and the next useful action.
