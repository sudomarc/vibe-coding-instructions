# Design Direction Skill

Treat design as a system of decisions, not decoration.

Before coding, establish product purpose, audience, visual tone, information hierarchy, density, typography roles, color roles, imagery, interaction language and responsive priorities.

Inspect existing tokens, primitives, components and page patterns. Extend them when appropriate.

Quality requires obvious hierarchy, meaningful empty space, coherent states, accessible interaction and a deliberate visual point of view.

Do not use arbitrary gradients, shadows, animations or decorative UI to hide weak hierarchy.
