# Incident Protocol

1. Establish impact and affected systems.
2. Preserve relevant evidence.
3. Stabilize using the smallest safe action.
4. Communicate current facts and uncertainty.
5. Avoid speculative broad changes.
6. Verify recovery.
7. Build a timeline.
8. Identify root cause and contributing factors.
9. Add regression tests and corrective controls.
10. Record follow-up actions with owners and verification criteria.
