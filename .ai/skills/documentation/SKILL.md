# Documentation Skill

Document behavior, contracts, decisions, and operational procedures that a future maintainer needs. Keep documentation close to the source of truth. Remove stale instructions when changing behavior. Prefer concrete commands and examples that have been validated.

References: `references/doc-checklist.md`, `references/comment-policy.md`, `examples/runbook.md`.
