Inspect repository instructions, UI conventions, nearest existing components, responsive behavior and state requirements before editing.

Implement the smallest coherent change. Prefer composition over duplication and existing primitives over new libraries. Add heavy animation or 3D only when the product need and measured constraints justify it.

Run focused tests and type or lint checks where applicable. Use browser verification for user-visible changes when available. For visual changes, capture relevant states and viewports; for 3D or motion, include fallback or reduced-motion verification where applicable.

Inspect the final diff before completion.
