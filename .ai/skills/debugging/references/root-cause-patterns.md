# Root-Cause Patterns

Useful categories include:

- wrong input assumptions;
- invalid state transition;
- stale cache or derived state;
- concurrency or ordering bug;
- boundary condition;
- environment mismatch;
- configuration drift;
- dependency behavior change;
- serialization or parsing mismatch;
- authorization or trust-boundary error;
- data migration inconsistency.

Use these as hypotheses, not conclusions. Evidence must select the category.
