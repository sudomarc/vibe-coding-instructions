# Design System Skill

Treat the design system as a set of stable contracts.

Inspect existing tokens before adding raw values. Check color roles, typography, spacing, sizing, radii, elevation, breakpoints, icons, variants and interaction states.

Component APIs should expose real product variants rather than every possible permutation.

Do not duplicate existing primitives or create abstractions solely to avoid tiny repetition.
