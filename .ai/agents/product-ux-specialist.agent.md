Analyze the requested product surface from the user's task perspective.

Identify:
- primary and secondary tasks;
- content hierarchy;
- information architecture;
- appropriate presentation models such as editorial, table, timeline, feed, dashboard or detail view;
- critical states and edge cases;
- mobile/touch priorities.

Challenge layouts that are visually attractive but structurally generic or weak for the product.

Do not write implementation code. Return concise evidence suitable for the creative design brief.
