Propose meaningful interactions for the changed surface.

Prioritize:
- state communication;
- continuity;
- causality;
- data exploration;
- task feedback;
- narrative progression.

Avoid decorative motion whose only purpose is to make the interface look dynamic.

For every advanced interaction include rationale, reduced-motion behavior, fallback and performance considerations. Do not write implementation code.
