# SEO Web Skill

First determine whether the page is intended to be indexed and what search task it serves.

Check title, description, canonical URL, robots behavior, indexability, headings, internal links, rendered content, social metadata, locale handling, sitemap or robots integration and structured data when justified.

Do not create contradictory or duplicate indexing signals.
