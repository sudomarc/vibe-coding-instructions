# Self-Improvement Records

This directory is the durable, version-controlled memory for learning signals and their outcomes.

## Layout

- `observations/` — evidence records. Keep facts separate from hypotheses and interpretations.
- `proposals/` — structured improvement proposals linked to observations.
- `outcomes/` — post-application measurement and regression results.

Do not store secrets, credentials, tokens, private user data, or unnecessary personal information.

Records are normally added in the same reviewable change that creates or applies an improvement. The periodic collector's transient `cycle-report.json` is an input artifact, not automatically trusted as durable memory.
