# Context Management Skill

## Workflow

1. Freeze the current repository state conceptually.
2. Record the objective and scope.
3. Record instructions loaded and key decisions.
4. Record changed files and verification evidence.
5. Record failures, blockers, and unresolved questions.
6. Write exact next actions.
7. Resume from the handoff rather than reconstructing history from memory.

## Rules

Preserve facts, not narrative. Include commands and results when they matter. State what has not been verified.
